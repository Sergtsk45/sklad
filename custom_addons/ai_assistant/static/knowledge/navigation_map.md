# Навигационные ссылки Odoo

Этот файл помогает ассистенту понять, когда нужно вызвать tool
`get_navigation_link`. URL не перечисляются намеренно: ссылку можно брать
только из результата tool.

| Тема | Когда давать | Tool вызывает |
|---|---|---|
| Заказы поставщикам | Пользователь спрашивает, где посмотреть PO, заказы на покупку, закупки поставщикам | `get_navigation_link(topic="заказы поставщикам")` |
| Запросы КП | Пользователь ищет RFQ, ЗКП, запросы коммерческих предложений | `get_navigation_link(topic="запросы коммерческих предложений")` |
| Поставщики | Пользователь хочет открыть список поставщиков или карточки контрагентов-поставщиков | `get_navigation_link(topic="поставщики")` |
| Требования прорабов | Пользователь спрашивает про OR, требования на комплектацию, заявки прорабов | `get_navigation_link(topic="требования прорабов")` |
| Объекты | Пользователь ищет объекты/проекты для требований | `get_navigation_link(topic="объекты")` |
| Аналитика требований | Пользователь хочет статистику или аналитику требований | `get_navigation_link(topic="аналитика требований")` |
| Поступления | Пользователь спрашивает, где приемки, приходы, receipts | `get_navigation_link(topic="поступления")` |
| Внутренние перемещения | Пользователь ищет внутренние перемещения/переводы между складами | `get_navigation_link(topic="внутренние перемещения")` |
| Трансферы | Пользователь хочет общий список складских операций/трансферов | `get_navigation_link(topic="трансферы")` |
| Остатки товаров | Пользователь спрашивает общий отчет остатков или наличие без конкретного склада | `get_navigation_link(topic="остатки")` |
| Места хранения | Пользователь ищет локации, места хранения, locations | `get_navigation_link(topic="места хранения")` |
| Инвентаризация | Пользователь спрашивает, где открыть физическую инвентаризацию | `get_navigation_link(topic="инвентаризация")` |
| Товары | Пользователь ищет товары, продукты, номенклатуру | `get_navigation_link(topic="товары")` |
| Контакты | Пользователь спрашивает, где контакты или партнеры | `get_navigation_link(topic="контакты")` |
| Мои настройки | Пользователь хочет открыть свой профиль или персональные настройки | `get_navigation_link(topic="мои настройки")` |
| CRM воронка | Пользователь спрашивает про CRM pipeline или воронку продаж | `get_navigation_link(topic="crm воронка")` |
| Лиды | Пользователь ищет CRM-лиды | `get_navigation_link(topic="лиды")` |
| Коммерческие предложения | Пользователь спрашивает про КП в продажах | `get_navigation_link(topic="коммерческие предложения")` |
| Заказы на продажу | Пользователь ищет заказы продаж | `get_navigation_link(topic="заказы на продажу")` |
| Аудит AI | Пользователь спрашивает про журнал или аудит AI Assistant | `get_navigation_link(topic="аудит ai")` |
| Чат AI | Пользователь спрашивает, где AI Assistant или чат ассистента | `get_navigation_link(topic="чат ai")` |
| Dashboard | Пользователь просит открыть главную панель или список приложений | `get_navigation_link(topic="dashboard")` |

Если пользователь спрашивает остатки по конкретному складу, например
«остатки на ОбМ-4», не выдумывай URL. Используй специализированный сценарий
по складу, когда он доступен, либо попроси уточнить товар/склад.
