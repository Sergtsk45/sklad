# Общие настройки Odoo 19

> **[DEMO - RST not available]** Этот файл сгенерирован как заглушка. Для получения реального контента выполните клонирование репозитория odoo/documentation и запустите скрипт без --demo.

## Шаг за шагом

### Настройка компании

1. Перейдите в **Настройки** → **Общие настройки**.
2. В разделе «Компании» проверьте название и реквизиты.
3. Загрузите логотип компании через кнопку загрузки изображения.
4. Укажите **Валюту** и **Страну** компании.

> **Примечание**: В Odoo 19 форма сохраняется автоматически.

### Управление пользователями

1. Перейдите в **Настройки** → **Пользователи и компании** → **Пользователи**.
2. Нажмите **Новое** для создания пользователя.
3. Укажите имя, email и установите права доступа.
4. Пользователь получит приглашение на email для установки пароля.
