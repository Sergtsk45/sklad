# Котировки и заказы на продажу

> **[DEMO - RST not available]** Этот файл сгенерирован как заглушка. Для получения реального контента выполните клонирование репозитория odoo/documentation и запустите скрипт без --demo.

**Ключевые слова**: котировка, quotation, заказ, продажа, счёт

## Шаг за шагом

### Создание котировки

1. Перейдите в **Продажи** → **Заказы** → **Котировки**.
2. Нажмите **Новое**.
3. Выберите **Клиента** в поле «Клиент».
4. Добавьте товары в раздел «Строки заказа» через **Добавить строку**.
5. Укажите количество и цену для каждого товара.
6. Нажмите **Отправить по эл. почте** или **Подтвердить** для оформления заказа.

> **Примечание**: После подтверждения котировка становится заказом на продажу.

### Выставление счёта

1. Откройте подтверждённый заказ на продажу.
2. Нажмите **Выставить счёт**.
3. Проверьте данные счёта и нажмите **Подтвердить**.
4. Отправьте счёт клиенту через **Отправить по эл. почте**.
