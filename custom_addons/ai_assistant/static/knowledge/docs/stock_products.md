# Управление товарами на складе

> **[DEMO - RST not available]** Этот файл сгенерирован как заглушка. Для получения реального контента выполните клонирование репозитория odoo/documentation и запустите скрипт без --demo.

**Ключевые слова**: товар, product, хранимый, инвентаризация

## Шаг за шагом

### Создание нового товара

1. Перейдите в **Склад** → **Товары** → **Товары**.
2. Нажмите **Новое**.
3. Укажите **Тип товара**: Хранимый, Расходный или Услуга.
4. Заполните **Единица измерения** и установите цены.

> **Примечание**: Только товары типа «Хранимый» формируют складские остатки.

### Инвентаризация

1. Перейдите в **Склад** → **Операции** → **Инвентаризация**.
2. Нажмите **Новое** для создания записи инвентаризации.
3. Добавьте товары и укажите фактические количества.
4. Нажмите **Подтвердить** для применения корректировки.
