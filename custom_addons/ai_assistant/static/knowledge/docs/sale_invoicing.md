# Выставление счетов в модуле Продажи

> **[DEMO - RST not available]** Этот файл сгенерирован как заглушка. Для получения реального контента выполните клонирование репозитория odoo/documentation и запустите скрипт без --demo.

**Ключевые слова**: счёт, invoicing, оплата, выставление

## Шаг за шагом

### Политики выставления счетов

1. Перейдите в **Продажи** → **Конфигурация** → **Настройки**.
2. В разделе «Выставление счетов» выберите политику: по заказанному или по доставленному количеству.
3. Нажмите **Подтвердить** для сохранения.

> **Примечание**: Политика «по доставленному» требует подтверждения доставки перед выставлением счёта.
