# Воронка продаж CRM

> **[DEMO - RST not available]** Этот файл сгенерирован как заглушка. Для получения реального контента выполните клонирование репозитория odoo/documentation и запустите скрипт без --demo.

**Ключевые слова**: воронка, pipeline, kanban, этап, возможность

## Шаг за шагом

### Управление воронкой

1. Перейдите в **CRM** → **Продажи** → **Воронка**.
2. Просматривайте возможности в виде **Канбан** или **Список**.
3. Перетащите карточку в следующий этап для обновления статуса.
4. Кликните на карточку для просмотра деталей возможности.

> **Примечание**: Этапы воронки настраиваются в **CRM** → **Конфигурация** → **Этапы**.

### Планирование активностей

1. Откройте возможность.
2. Нажмите **Запланировать активность** в разделе активностей.
3. Выберите тип активности (звонок, встреча, email).
4. Укажите дедлайн и ответственного.
5. Нажмите **Запланировать**.
