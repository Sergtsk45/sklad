# Управление складами в Odoo 19

> **[DEMO - RST not available]** Этот файл сгенерирован как заглушка. Для получения реального контента выполните клонирование репозитория odoo/documentation и запустите скрипт без --demo.

**Ключевые слова**: склад, warehouse, местонахождение, маршрут

## Шаг за шагом

### Создание нового склада

1. Перейдите в **Склад** → **Конфигурация** → **Склады**.
2. Нажмите **Новое**.
3. Заполните поле **Название склада** и **Краткое имя**.
4. Настройте маршруты склада в разделе **Конфигурация**.

> **Примечание**: В Odoo 19 форма сохраняется автоматически.

### Настройка местонахождений

1. Перейдите в **Склад** → **Конфигурация** → **Местонахождения**.
2. Выберите местонахождение или создайте новое через **Новое**.
3. Укажите тип местонахождения и родительское местонахождение.
