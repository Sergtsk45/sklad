# Warehouses

## Шаг за шагом

**Ключевые слова**: warehouse, warehouses, склад, склады, создать склад, create warehouse, настройки, маршруты, multi-step routes, краткое имя

### Конфигурация

**Навигация:**
- Склад app → Конфигурация → Настройки
- Производство app → Конфигурация → Настройки

> **Примечание**: The **Краткое имя** appears on warehouse documents, so it is recommended to use a memorable one, like "WH[first letters of location]" (e.g. `WHA`, `WHB`, etc.).
> **Примечание**: The options below are available **only** when the *Multi-Step Маршруты* feature is enabled in **Склад app → Конфигурация → Настройки**.
