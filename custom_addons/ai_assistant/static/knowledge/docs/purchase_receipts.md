# Приёмка товаров по заказу закупки

> **[DEMO - RST not available]** Этот файл сгенерирован как заглушка. Для получения реального контента выполните клонирование репозитория odoo/documentation и запустите скрипт без --demo.

**Ключевые слова**: приёмка, receipt, поступление, закупка

## Шаг за шагом

### Приёмка поступления

1. Откройте заказ поставщику.
2. Нажмите кнопку **Поступления** (счётчик в верхней части).
3. В поступлении проверьте количества в колонке **Выполнено**.
4. Отредактируйте фактические количества при необходимости.
5. Нажмите **Подтвердить** для завершения приёмки.

> **Примечание**: При частичной приёмке система предложит создать дозаказ на оставшееся количество.
