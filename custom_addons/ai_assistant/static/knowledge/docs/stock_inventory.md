# Инвентаризация склада

> **[DEMO - RST not available]** Этот файл сгенерирован как заглушка. Для получения реального контента выполните клонирование репозитория odoo/documentation и запустите скрипт без --demo.

## Шаг за шагом

### Проведение инвентаризации

1. Перейдите в **Склад** → **Операции** → **Инвентаризация**.
2. Нажмите **Новое** для создания акта инвентаризации.
3. Выберите местонахождение и добавьте товары.
4. Заполните фактические количества в колонке **Количество**.
5. Нажмите **Подтвердить** для сохранения результатов.

> **Примечание**: Разница между учётным и фактическим количеством автоматически корректируется при подтверждении.
