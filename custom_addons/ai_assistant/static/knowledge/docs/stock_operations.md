# Складские операции: поступления и отгрузки

> **[DEMO - RST not available]** Этот файл сгенерирован как заглушка. Для получения реального контента выполните клонирование репозитория odoo/documentation и запустите скрипт без --demo.

**Ключевые слова**: поступление, receipt, отгрузка, delivery, перемещение

## Шаг за шагом

### Обработка поступления товаров

1. Перейдите в **Склад** → **Операции** → **Поступления**.
2. Откройте поступление в статусе «Готово».
3. Проверьте количества в колонке **Выполнено**.
4. Нажмите **Проверить наличие** если количества не заполнены.
5. Нажмите **Подтвердить** для завершения поступления.

> **Примечание**: Если количество меньше заказанного — система предложит создать дозаказ.

### Обработка отгрузки товаров

1. Перейдите в **Склад** → **Операции** → **Отгрузки**.
2. Откройте отгрузку в статусе «Готово».
3. Нажмите **Проверить наличие** для резервирования товаров.
4. Проверьте и скорректируйте количества при необходимости.
5. Нажмите **Подтвердить** для подтверждения отгрузки.
