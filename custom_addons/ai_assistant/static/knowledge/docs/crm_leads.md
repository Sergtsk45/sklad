# Работа с лидами в CRM

> **[DEMO - RST not available]** Этот файл сгенерирован как заглушка. Для получения реального контента выполните клонирование репозитория odoo/documentation и запустите скрипт без --demo.

**Ключевые слова**: лид, lead, crm, возможность, opportunity

## Шаг за шагом

### Создание лида

1. Перейдите в **CRM** → **Лиды**.
2. Нажмите **Новое**.
3. Заполните имя контакта, компанию и контактные данные.
4. Укажите **Ожидаемую выручку** и **Вероятность**.
5. Назначьте **Ответственного** менеджера.

> **Примечание**: Лиды можно конвертировать в возможности через меню **Действие**.

### Конвертация лида в возможность

1. Откройте лид.
2. Нажмите **Конвертировать в возможность**.
3. Укажите клиента и контактное лицо.
4. Выберите воронку продаж и этап.
5. Нажмите **Конвертировать**.
