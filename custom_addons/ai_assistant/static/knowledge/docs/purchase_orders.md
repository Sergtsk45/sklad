# Заказы на закупку

> **[DEMO - RST not available]** Этот файл сгенерирован как заглушка. Для получения реального контента выполните клонирование репозитория odoo/documentation и запустите скрипт без --demo.

**Ключевые слова**: закупка, purchase, поставщик, запрос котировки, заказ поставщику

## Шаг за шагом

### Создание запроса котировки

1. Перейдите в **Закупки** → **Заказы** → **Запросы котировок**.
2. Нажмите **Новое**.
3. Выберите **Поставщика**.
4. Добавьте товары через **Добавить строку**.
5. Укажите количество, цену и ожидаемую дату поставки.
6. Нажмите **Подтвердить заказ** для создания заказа поставщику.

> **Примечание**: После подтверждения запрос котировки становится заказом поставщику.

### Отправка заказа поставщику

1. Откройте подтверждённый заказ поставщику.
2. Нажмите **Отправить по эл. почте** для отправки заказа.
3. Заполните тему и текст письма.
4. Нажмите **Отправить**.
