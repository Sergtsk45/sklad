# Формат таблицы договор-счёта ОАО УПТК «Амурстрой»

## Заголовок документа

```
Договор-Счет № П000014101 от 23.06.26
```

OCR может распознать номер как `14101` — для Odoo нормализовать в `П000014101`.

## Колонки таблицы

| Колонка | Поле JSON | Примечание |
|---------|-----------|------------|
| Товар | `name` | Может переноситься на 2–3 строки OCR |
| Кол-во | `qty` | Целое |
| Ед. | `unit` | `шт`, `кг`, `уп`, `пара` |
| Цена | `price` | Цена за единицу **до** скидки |
| Сумма без скидки | `amount_before_discount` | `qty × price` |
| Скидка | `discount_amount` | Обычно 5% от суммы без скидки |
| Сумма | `amount` | К оплате по строке (после скидки) |

**Формула:** `amount ≈ amount_before_discount × 0.95` (скидка 5%).

## Итоги в подвале

Две разные суммы:

| Строка | Смысл | Использовать для PO |
|--------|-------|---------------------|
| `Всего наименований N, на сумму 21 553,60 руб.` | Сумма **без НДС** | **Да** — сверка `items_sum` |
| `Итого: 21 973,60` | С НДС | Справочно |
| `В том числе НДС: 3 006,71` | НДС | Справочно |

## Типичные OCR-ошибки

| OCR | Исправление |
|-----|-------------|
| `750лл` | `750мл` |
| `Сунна` | `Сумма` |
| `Гамка` | `Гайка` |
| `СУМ 934` | `DIN 934` |
| `ate армированный` | `Лента армированная` |
| `Пacreapirene` | `Растворитель` |
| `95 00 4750.00` | `95 шт` + суммы |
| `(36 308.00` | номер строки `2` + цена `308.00` |
| `т 00` (в сумме) | `427.00` |
| `1865.20` | `186.20` |

## Строки, которые не являются товарами

- «В продаже имеются Маты…»
- «Уважаемые клиенты»
- Подписи директора / бухгалтера
- Условия оплаты и хранения
