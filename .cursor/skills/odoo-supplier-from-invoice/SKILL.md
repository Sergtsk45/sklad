# Odoo: Добавление поставщика из счёта

## Что делает этот скилл

Читает PDF или Excel-счёт, извлекает реквизиты поставщика и записывает
контрагента в Odoo (`res.partner`). Если контрагент уже есть — дополняет
недостающие данные.

---

## Шаг 1 — Чтение файла

### PDF

1. Проверь текстовый слой (`pdfplumber`, `len(page.chars)`).
2. **Скан без текста** (`chars == 0`) → скилл **scanned-invoice-parsing**
   (OCR через `scripts/ocr_parse.py`, постобработка `ocr-corrections.md`).
3. **Текстовый PDF** — читай напрямую или через `extract_invoice()` из `ai_assistant`.

```python
import pdfplumber
with pdfplumber.open(path) as pdf:
    has_text = len(pdf.pages[0].chars) > 0
```

### Excel (.xlsx)
```python
from openpyxl import load_workbook
wb = load_workbook("/mnt/user-data/uploads/filename.xlsx", read_only=True)
ws = wb.active
for row in ws.iter_rows(max_row=40, values_only=True):
    if any(c is not None for c in row):
        print(row)
```

---

## Шаг 2 — Извлечение реквизитов поставщика

Ищи блок **«Поставщик:»** (не «Покупатель»). Извлекай:

| Поле Odoo       | Что искать в документе                        |
|-----------------|-----------------------------------------------|
| `name`          | Полное наименование (ООО, АО, ИП + ФИО)       |
| `vat`           | ИНН (10 цифр — юрлицо, 12 цифр — ИП/физлицо) |
| `comment`       | КПП (если есть, сохраняй в примечание)        |
| `is_company`    | `true` — ООО/АО/ЗАО; `false` — ИП/физлицо    |
| `street`        | Улица, дом, корпус, офис/квартира             |
| `city`          | Город                                         |
| `zip`           | Почтовый индекс                               |
| `phone`         | Телефон поставщика                            |
| `email`         | Email поставщика (если указан)                |
| `supplier_rank` | Всегда `1` (отмечает как поставщика)          |

### Чего НЕ нужно вносить
- Банковские реквизиты (БИК, р/с, к/с, название банка) — в `res.partner` не хранятся
- Реквизиты покупателя — только поставщик

### Определение типа контрагента (`is_company`)
- `ООО`, `АО`, `ЗАО`, `ПАО`, `ОАО`, `МУП`, `ГУП` → `true`
- `ИП` + ФИО → `false`
- Просто ФИО без ИП → `false`

## Шаг 4 — Проверка дубликата по ИНН

**Всегда** проверяй перед созданием:

```
odoo:search_records(
  model="res.partner",
  domain=[["vat", "=", "<ИНН>"]],
  fields=["id", "name", "vat", "phone", "email", "street", "city", "supplier_rank"]
)
```

### Если запись не найдена → создать (Шаг 5а)
### Если запись найдена → обновить (Шаг 5б)

---

## Шаг 5а — Создание нового контрагента

```
odoo:create_record(
  model="res.partner",
  values={
    "name": "...",
    "vat": "...",
    "is_company": true/false,
    "street": "...",
    "city": "...",
    "zip": "...",
    "phone": "...",
    "email": "...",          # только если есть
    "supplier_rank": 1
  }
)
```

---

## Шаг 5б — Обновление существующего контрагента

Обновляй только **пустые** поля — не затирай уже заполненные данные.
Всегда обновляй `supplier_rank: 1` если он был 0.

```
odoo:update_record(
  model="res.partner",
  record_id=<id>,
  values={<только пустые поля + supplier_rank если был 0>}
)
```

## Пакетная обработка (несколько файлов)

Если пользователь загружает несколько счётов подряд — обрабатывай
каждый последовательно по той же схеме. Для каждого файла:
1. Извлечь реквизиты
2. Проверить дубликат
3. Создать или обновить
4. Сообщить результат

---

## Частые ситуации

### КПП отсутствует
У ИП и физлиц КПП нет — это нормально, не запрашивай.

### Один ИНН, но разные названия
Доверяй ИНН. Если нашёл запись с таким же ИНН но другим названием —
сообщи пользователю о расхождении перед обновлением.

### Поставщик — это сам покупатель (наша компания)
Иногда в счёте покупатель — та же компания что в Odoo (например
«Теплосервис-Комплект»). Такой контрагент уже есть как собственная
организация — не создавай дубликат, сообщи пользователю.

### ИНН не читается / отсутствует
Если ИНН не удалось извлечь — сообщи пользователю и попроси уточнить
вручную. Не создавай запись без ИНН (нет возможности проверить дубликат).

### MCP-сервер не отвечает
Если Odoo MCP не отвечает — сообщи пользователю что сервер недоступен
и предложи попробовать позже. Сохрани извлечённые реквизиты в ответе
чтобы пользователь мог занести их вручную.
