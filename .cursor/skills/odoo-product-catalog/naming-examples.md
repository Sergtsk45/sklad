Торговые формулировки счёта оставляй в `product.supplierinfo.product_name`.

## Когда две карточки обязательны

| Признак | Пример |
|---------|--------|
| Разный PN | Fiber-G 40 PN20 vs PN25 |
| Разный IP | ЩМП 300×400×200 IP66 vs без IP66 / другой артикул IP |
| Разная толщина / сечение | НШВИ 0,75-8 vs 1,5-8 |
| Разный размер площадки | 20×20 vs 25×25 |
| Узел vs деталь | Переход с манжетой vs только манжета |
| Цвет/полюс клеммы (если ведёте раздельно) | 2,5 мм² синяя vs серая vs PE |

## Услуги

| Счёт | Карточка |
|------|----------|
| Резка трубы 15-30мм | Резка трубы профильной 15–30 мм (`type=service`) |
| Доставка / разгрузка | Отдельная услуга, не материал |

## Символы и единицы

- Размеры: знак умножения `×` (не `x`/`*`), десятичная запятая `3,2`.
- Ду / DN — как принято в каталоге проекта (обычно **Ду** для РФ).
- Длина хлыста: `длина 6 м` или `L6000 мм` — единообразно внутри категории.
