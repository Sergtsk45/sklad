# Словарь постобработки OCR для счетов

Применяй **после** Tesseract, **до** вывода пользователю.

## Организации и география

| OCR (ошибка) | Исправление |
|--------------|-------------|
| Анурстрой, Амурстрой (с опечаткой) | **Амурстрой** |
| УПТК "Анурстрой" | **ОАО УПТК «Амурстрой»** |
| Теплосервис- Комплект, Конплект | **ООО «Теплосервис-Комплект»** |
| Анурская | **Амурская** |
| ла говещенск | **Благовещенск** |
| uptkamurstroy@imailru | uptkamurstroy@mail.ru |

## Номенклатура крепежа

| OCR (ошибка) | Исправление | Примечание |
|--------------|-------------|------------|
| СУМ 934, СУМ934, ГОСТ 934 | **DIN 934** | шестигранная гайка |
| Гамка | **Гайка** | |
| шестигоан, шеститан, шестиган | **шестигран.** | |
| МЕ, МВ | **М6** | метрическая резьба M6 |
| Болт МЕ х 10 | **Болт М6 × 10** | |
| СЧ (в контексте ГОСТ) | **ГОСТ** | если рядом стандарт, не путать с «счёт» |
| wr, wT | **кг** | единица веса в артикуле |

## Стандарты (не путать)

- **DIN 934** — гайка шестигранная (не ГОСТ)
- **DIN 933** — болт с шестигранной головкой (часто в паре с DIN 934)
- **ГОСТ 7798**, **ГОСТ 5915** — болты/гайки по ГОСТ (если явно указано в оригинале)

При сомнении — спроси пользователя (как с DIN 934).

## Игнорировать (не позиции счёта)

Строки без количества/цены в таблице:

- «В продаже имеются Маты…»
- «3480 рублей» без строки таблицы
- «Уважаемые клиенты»
- Условия оплаты, хранения, возврата

## Проверка таблицы

```
Σ (сумма по строкам) == Итого
```

Если не сходится — перечитать кроп таблицы с `--psm 4` или уточнить у пользователя.
