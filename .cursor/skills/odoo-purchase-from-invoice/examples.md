# Примеры: закупка из счёта

Скилл: [SKILL.md](SKILL.md). Имена, id и URL ниже — иллюстрация, не копируй
их в другой инстанс.

## 1. Склад назван

Пользователь: «создай закупку по счёту … на Ломоносова 164».

1. Явная команда — продолжай.
2. Парсинг: номер из PDF, не из файла.
3. Дубль `partner_ref` — нет.
4. Поставщик по ИНН — найден.
5. Склад: `ilike` по имени → один `in_type_id`.
6. Карточки по `odoo-product-catalog`.
7. `create_record(purchase.order)` в draft с этим `picking_type_id`.
8. Сверка `amount_total` с «Итого».

## 2. Склад не назван — спросить

Пользователь: «создай закупку по счёту …» (без склада).

Не подставляй основной / «склад металла» / последний объект.

1. Распарси, найди поставщика, подготовь карточки.
2. `search_records(stock.warehouse, active=true)`.
3. Предложи 3–6 вариантов, например:
   - склад из этой сессии (только что созданный контейнер);
   - склад последнего PO этого поставщика;
   - склад по типу товара (металл, расходники).
4. Спроси и **жди**. Create PO — только после ответа.

## 3. Пересчёт шт. → кг

Счёт: «Сталь листовая цинк … — 3 шт, вес 37,80 кг, 145 ₽/кг, сумма 5 481».
Карточка в **кг**.

Строка PO: `product_qty=37.8`, `price_unit=145`, UoM карточки (кг).
Не заказывать 3 шт на карточку в кг.

Труба L6 м, карточка в **шт.**, цена в счёте за кг: `price_unit = сумма / 17 шт`.

## 4. Дубль

`partner_ref` уже есть на P00xxx. Не create. Ответ: ссылка, сумма, склад.
Пустой черновик того же поставщика без этого номера — не трогать.

## 5. Стоп OCR

Парсер: `needs_review: true` или сумма строк ≠ итого. Покажи таблицу и
расхождение. PO не создавай, пока пользователь не подтвердит цифры.

## 6. Номер из PDF, не из файла

Файл: `…№ НФ-1156….pdf`. В PDF: «Счет на оплату № 1156».
`partner_ref` = `1156`, не `НФ-1156`.

В PDF «№ УТ-2526» → `УТ-2526`. В PDF «№ П000014256» → `П000014256`.

## 7. Налоги

У товаров пустой закупочный налог, в счёте суммы **с НДС**.
Пиши `price_unit` из «сумма с НДС» / qty, чтобы `amount_total` = «Итого».
Не накидывай 22% сверху.

## Перенос в другой проект

Скопируй каталог:

```text
~/.cursor/skills/odoo-purchase-from-invoice/
```

или `.cursor/skills/odoo-purchase-from-invoice/` в репозитории.

Нужны: Odoo Purchase + Inventory, MCP create/search/get. Склады, UoM и
налоги бери из **целевой** базы. Локальные ИНН и форматы счетов — отдельное
правило репозитория, не этот скилл.
