# Примеры: создание склада

Скилл: [SKILL.md](SKILL.md). Имена и id ниже — иллюстрация, не копируй их
в другой инстанс.

## 1. Только склад

Пользователь: «Создай новый склад Контейнер_5».

1. Явная команда — продолжай.
2. Поиск: складов с именем «Контейнер» нет (кроме «Основной склад (20 футовый
   контейнер)» — другое имя). Кода `Кнт5` нет.
3. Образец: основной контейнер — `one_step` / `ship_only` / `buy_to_resupply`.
4. Create:

```text
create_record("stock.warehouse", {
  "name": "Контейнер_5",
  "code": "Кнт5",
  "company_id": <из образца>,
  "partner_id": <из образца>,
  "buy_to_resupply": true,
  "reception_steps": "one_step",
  "delivery_steps": "ship_only"
})
```

5. Отчёт: id, код `Кнт5`, `lot_stock_id` = `Кнт5/Наличие`, тип поступления
   `Контейнер_5: Поступления`. Полок нет — предложи, если уместно.

## 2. Склад + полки

Пользователь: «создай полки на нём: Н1, Н2, Н3, С1, С2, С3, В1, В2, В3».

Склад уже есть (`lot_stock_id` известен). Для каждой полки:

```text
create_record("stock.location", {
  "name": "Н1",
  "usage": "internal",
  "location_id": <lot_stock_id>,
  "company_id": <company_id>
})
```

Имена **как в запросе**. Итог:

| Ярус | Путь |
|------|------|
| Н | `Кнт5/Наличие/Н1` … `Н3` |
| С | `Кнт5/Наличие/С1` … `С3` |
| В | `Кнт5/Наличие/В1` … `В3` |

Putaway не включать, пока не попросили.

## 3. Дубль

Пользователь: «создай склад Контейнер_5», а склад с таким именем уже есть.

Не create. Ответ: склад уже существует, id, ссылка, код, локация запаса.
Если в том же сообщении просят полки — создавай только недостающие дети
`lot_stock_id`.

## 4. Пополнение с базы

Пользователь: «создай склад объекта O019, пополнять с основного».

1. Найди основной склад по имени/коду в **этой** базе.
2. Создай объектный склад с уникальным кодом (например `O019`).
3. После create:

```text
update_record("stock.warehouse", <id>, {
  "resupply_wh_ids": [[6, 0, [<id_основного>]]]
})
```

Перед `[[6, 0, ...]]` прочитай текущие `resupply_wh_ids`.

## 5. Недостаточно данных

Пользователь: «надо бы ещё один контейнер».

Это не повелительная команда с именем. Спроси название (и полки, если нужны).
MCP create не вызывай.

## Перенос в другой проект

Скопируй каталог скилла:

```text
~/.cursor/skills/odoo-create-warehouse/
```

либо `.cursor/skills/odoo-create-warehouse/` внутри репозитория.

Нужны: Odoo Inventory, MCP с create/search/get. Подставь company/partner
из складов **целевой** базы, не из примеров выше.
