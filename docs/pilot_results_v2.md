## Инструкция по прогону

### Подготовка
1. Убедитесь, что Odoo запущен: `docker compose -f docker-compose.local.yml up -d`
2. Войдите под тестовым пользователем (ru_RU локаль)
3. Откройте AI-ассистент (FAB-кнопка в правом нижнем углу)
4. Проверьте настройки: Настройки → AI-ассистент → text_model и vision_model

### Для текстовых сценариев (T-01..T-10)
1. Перейдите на указанный экран
2. Задайте вопрос из колонки «Вопрос»
3. Запишите ответ AI в «Ответ AI»
4. Оцените: ✅ (полностью корректно) / ⚠️ (есть замечания) / ❌ (неверно/неработает)

### Для vision-сценариев (V-01..V-05)
1. Перейдите на указанный экран
2. Убедитесь что виден нужный контент (откройте список/форму)
3. Задайте вопрос-триггер из колонки «Вопрос»
4. Следите за индикатором «Делаю скриншот...» → «Думаю...»
5. Запишите был ли скриншот сделан и ответ AI
6. Оцените результат

### Команда для проверки логов
```bash
docker compose -f docker-compose.local.yml logs -f odoo | grep -E "vision|screenshot|AI"
```
