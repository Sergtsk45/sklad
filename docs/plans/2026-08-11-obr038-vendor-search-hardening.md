# План: устранение замечаний ревью OBR-038

**Дата:** 2026-08-11  
**Статус:** Реализовано и проверено локально; ожидает деплоя  
**Основание:** ревью коммита `9766686`

## Цель

Сделать поиск товара по прайсу выбранного поставщика корректным для вариантов
товара и нескольких компаний, исключить сохранение несовместимой пары
«поставщик — товар» и сохранить предсказуемое время ответа autocomplete.

## Работы

### OBR-038-F1 — Корректный домен каталога

- Учитывать `product.supplierinfo.product_id`: variant-specific строка прайса
  разрешает только указанный вариант; строка без `product_id` разрешает все
  варианты шаблона.
- Учитывать только глобальные строки прайса и строки текущей компании.
- Одинаково применять правила к обычному поиску, торговому имени и артикулу.

### OBR-038-F2 — Ограниченный поиск торговых имён

- Ограничивать выборку на уровне `product.product`, используя подзапросы по
  `product.supplierinfo`, а не загружать все совпавшие строки прайса в Python.
- Загружать supplierinfo для подписей только для уже ограниченного набора
  найденных товаров.
- Для нескольких записей выбирать variant-specific запись раньше общей.

### OBR-038-F3 — Смена поставщика

- При смене `preferred_vendor_id` оставить товар, если он есть в прайсе нового
  поставщика для текущей компании и варианта.
- Иначе очистить несовместимые данные товара и вернуть строку в состояние,
  требующее сопоставления.
- Сохранить существующее снятие `manual_vendor_required`.

### OBR-038-T1 — Дополнительные тесты

- Variant-specific supplierinfo не возвращает соседний вариант шаблона.
- Template-wide supplierinfo возвращает все варианты шаблона.
- Строка прайса другой компании не попадает в каталог; глобальная попадает.
- Смена поставщика очищает несовместимый товар и сохраняет совместимый.
- Несколько supplierinfo дают корректную variant-specific подпись.
- Лимит autocomplete соблюдается; поиск не выполняет неограниченную
  материализацию строк прайса.

### OBR-038-V1 — Проверки и ревью
